# Format A Template Pack — Us.v2 Carousel (Starter)

This pack is compatible with the Content Ops Template Pack uploader.

## Contents
- `manifest.json` — required; declares output + per-slide placeholder boxes
- `template.html` — HTML slide template with `{{placeholder}}` tokens
- `styles.css` — layout + styling
- `script.js` — lightweight shrink-to-fit helper (optional)

## Placeholders (tokens)
- `{{headline}}`
- `{{body}}`
- `{{footer}}`
- `{{page_number}}`

## Notes
- Output size is `1080×1350` (Instagram 4:5 carousel).
- This is a starter pack: it uses the same layout for all slides.
